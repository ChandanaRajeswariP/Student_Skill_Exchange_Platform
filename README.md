# SkillSwap — Student Skill Exchange Platform

SkillSwap helps students teach and learn skills from one another. Students can create profiles, discover peers, arrange learning sessions, and share resources.

## Features

- Student registration and profiles
- Teaching and learning skill lists
- Student discovery
- Session booking and management
- Learning resource library
- Local MySQL and MongoDB storage

## Technology

JavaScript, React, Next.js, Express, MySQL, and MongoDB.

## Run the packaged Windows demo

The self-contained Windows package is for 64-bit Windows.

1. Extract the complete Windows package.
2. Double-click `START-SKILLSWAP.bat`.
3. Open [http://127.0.0.1:3000/](http://127.0.0.1:3000/) if the browser does not open automatically.
4. When finished, double-click `STOP-SKILLSWAP.bat`.

The package includes the local runtimes and databases needed for the demo. The source-only GitHub repository excludes bundled runtimes and `node_modules`, so a source checkout is not the same as the ready-to-run Windows package.

## Local data and security

This project is intended as a local educational demo. Keep local `.env` files and database data private. Do not expose the demo server to the public internet.
